## 📓 Notebooks

### 1. Basic Scanpy Spatial Analysis
**Source:** [scanpy-tutorials.readthedocs.io](https://scanpy-tutorials.readthedocs.io/en/latest/spatial/basic-analysis.html)

Covers the fundamental Scanpy workflow for spatial transcriptomics:
- Loading Visium data with `sc.datasets.visium_sge()`
- QC metrics: total counts, mitochondrial percentage, gene detection
- Normalization → HVG selection → PCA → UMAP → Leiden clustering
- Spatial visualization with `sc.pl.spatial()` overlaid on H&E images
- Cluster marker gene detection via `sc.tl.rank_genes_groups()`
- **Bonus:** MERFISH example (Xia et al. 2019) — coordinate-based spatial data

### 2. Visium Fluorescence Data Analysis
**Source:** [squidpy.readthedocs.io — Visium Fluo](https://squidpy.readthedocs.io/en/stable/notebooks/tutorials/tutorial_visium_fluo.html)

Focuses on multi-channel fluorescence image analysis alongside gene expression:
- Dataset: Visium mouse brain coronal section (DAPI, anti-NEUN, anti-GFAP channels)
- Image preprocessing with `sq.im.process()` (smoothing)
- Cell segmentation with `sq.im.segment()` (watershed algorithm)
- Segmentation feature extraction: cell counts per spot, channel intensities
- Multi-scale image feature extraction: summary, histogram, texture features
- Leiden clustering in image feature space vs. gene-expression space

### 3. Visium H&E Data Analysis
**Source:** [squidpy.readthedocs.io — Visium H&E](https://squidpy.readthedocs.io/en/stable/notebooks/tutorials/tutorial_visium_hne.html)

Full spatial statistics workflow on H&E-stained Visium data:
- Dataset: Mouse brain coronal section (pre-annotated clusters)
- Multi-scale summary feature extraction from H&E image
- Image-based vs. gene-based cluster comparison
- **Spatial graph construction** with `sq.gr.spatial_neighbors()`
- **Neighborhood enrichment analysis** with `sq.gr.nhood_enrichment()`
- **Co-occurrence scoring** across spatial dimensions
- **Ligand-receptor interaction analysis** (CellPhoneDB re-implementation in Squidpy + Omnipath)

### 4. Xenium Single-Cell Spatial Analysis
**Source:** [squidpy.readthedocs.io — Xenium](https://squidpy.readthedocs.io/en/stable/notebooks/tutorials/tutorial_xenium.html)

Analysis of sub-cellular resolution Xenium data using the SpatialData framework:
- Dataset: Xenium Human Lung Cancer (161,000 cells × 480 genes)
- Reading Xenium output with `spatialdata-io` and converting to Zarr
- QC: transcript counts, control probe %, cell area, nucleus-to-cell ratio
- Filtering, normalization, PCA, UMAP, Leiden clustering
- Spatial scatter visualization with `sq.pl.spatial_scatter()`
- **Centrality scores:** closeness, degree, and clustering coefficient
- **Ripley statistics** for spatial point pattern analysis

## 🔑 Key Concepts Learned

| Concept | Description |
|---------|-------------|
| **AnnData** | Core data structure storing count matrix + metadata + embeddings |
| **Visium** | Spot-based spatial transcriptomics (55 µm spots) |
| **Xenium** | Sub-cellular single-molecule resolution spatial transcriptomics |
| **MERFISH** | Multiplexed fluorescence in situ hybridization |
| **Leiden clustering** | Graph-based community detection algorithm |
| **UMAP** | Dimensionality reduction for visualization |
| **Neighborhood enrichment** | Statistical test for spatial co-localization of clusters |
| **Co-occurrence score** | Conditional probability of observing clusters at increasing radii |
| **Ligand-receptor analysis** | Inference of cell-cell communication from spatial context |
| **Ripley statistics** | Point process statistics for spatial pattern analysis |
